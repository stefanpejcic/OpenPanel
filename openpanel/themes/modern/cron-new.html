Cron Jobs

Create Cron Job

Run a command inside one of your containers on a schedule. To add several jobs at once, use the File Editor.

Command

What to run. Paths are inside the container, your sites are under /var/www/html/.

Runs with the container's shell. Output goes to the Logs tab.

Container

Where the command runs. PHP and WP-CLI need a PHP container, mysqldump needs your database container.

Picked , your default PHP version, for this PHP command. Picked , your database container, for this MySQL command. One of the containers on your account.

Schedule

When it runs, in the cron time zone ().

Expression Format
6 fields, seconds first: second minute hour day month weekday, or a descriptor like @every 2h.
Next runs

Name

How the job shows up in the list and in the logs.

Overlap

For jobs that can take longer than the time between runs.

No overlap

Skip this run if the previous run of this job is still in progress.

Cancel
