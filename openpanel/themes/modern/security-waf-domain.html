App profiles

Some apps send data that can look like an attack, for example HTML when you save a post. A profile tells the firewall what is normal for that app, so you don't get blocked while your site stays protected.

Only turn on profiles for apps you actually run on this domain. Each profile relaxes a few checks on that app's own pages.
