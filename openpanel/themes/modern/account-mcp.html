Connecting an MCP client

Generate a token above, then point your MCP client at this server's https://panel.localhost:2083/mcp endpoint with the token as a Bearer credential.

Claude Code CLI
claude mcp add --transport http openpanel https://panel.localhost:2083/mcp \
  --header "Authorization: Bearer <your-token>"
Claude Desktop (claude_desktop_config.json)
"openpanel": {
  "url": "https://panel.localhost:2083/mcp",
  "headers": { "Authorization": "Bearer <your-token>" }
}
