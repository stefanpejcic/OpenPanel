# IP Blocker

Using the IP Blocker page you can block a range of IP addresses to prevent them from accessing your websites.

![IP Blocker page with a text area for IP addresses and CIDR ranges to block](/img/openpanel-screenshots/advanced/ip-blocker-form.png#gh-light-mode-only)
![IP Blocker page with a text area for IP addresses and CIDR ranges to block](/img/openpanel-screenshots/advanced/ip-blocker-form_dark.png#gh-dark-mode-only)

Enter the IP addresses or CIDR ranges you want to block in the textarea, one per line (e.g. `192.168.1.1`, `10.0.0.0/24`), then click **Save Changes**.

:::info
To unblock all previously blocked IPs, clear the textarea and click **Save Changes**.
:::
