# Database Wizard

The Database Wizard can be accessed on the [MongoDB](/docs/category/mongodb/) page by clicking the "Database Wizard" button. This tool is designed to streamline the creation of a new database, a new user, and granting that user a role on the database.

![MongoDB Database Wizard with steps to create a database, create a user with a password, and grant a role](/img/openpanel-screenshots/mongodb/wizard-form.png#gh-light-mode-only)
![MongoDB Database Wizard with steps to create a database, create a user with a password, and grant a role](/img/openpanel-screenshots/mongodb/wizard-form_dark.png#gh-dark-mode-only)

The wizard performs three steps in sequence:

1. **Create a database**
2. **Create a user**
3. **Grant a role on the database**, using the role selected in step 3 (`readWrite` by default)

Click **Create DB, User, and Grant Privileges** to run all three steps automatically.

Please ensure to save this data as the password will not be displayed again. However, you have the option to reset it at any time from the [Users](/docs/panel/mongodb/users) page.
