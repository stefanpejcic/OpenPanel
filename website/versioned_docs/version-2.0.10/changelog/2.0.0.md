Released on 28.08.2026

2.0 is the first Podman-based version of OpenPanel and represents a major rewrite:

- OpenAdmin has been [open sourced](https://github.com/stefanpejcic/openadmin) and rewritten in Go
- OpenPanel is now [90% open sourced](https://hub.docker.com/r/openpanel/openpanel-podman) - only the core and premium modules remain closed source
- Podman replaces Docker for container management

**Note:** As this is a complete rewrite, there is no update path from existing 1.X versions to 2.0. Automating a Docker-to-Podman migration across hundreds of users and servers isn't realistically feasible. Existing 1.X versions based on Docker remain fully supported, and updates are still planned — though no new features will be added to the 1.X line. Plan a clean reinstall to upgrade to 2.x properly. Enterprise users can get hands-on help from our team at info@openpanel.com.
