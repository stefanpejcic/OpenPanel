### Polish
- Docker module in OpenPanel UI is split into separate `terminal`, `change_image`, `change_ws`, and `change_db` modules (previously all bundled under `docker`), so each can be enabled/disabled independently in *OpenAdmin > Settings > Modules*.
- New *OpenAdmin > Services > Podman* page: podman info, image/volume/network listings, per-image pull/delete and bulk "pull all missing" / "delete unused" actions, per-image vulnerability (Trivy) scanning, and a system disk-usage breakdown.
- New *OpenAdmin > Server > Swap* page to view swap usage and resize, create, or drop the swap file.
- New *OpenAdmin > Backups* pages: system config backups (destination, trigger, one-click restore, run history) and user account backups.
- Added inline-edit options on *OpenAdmin > Users > `<username>`*: Locale, Web server, Database type, Varnish caching, and disabling 2FA.
- Added a one-click full account export option on *OpenAdmin > Users > \<username\> > Export*, with delete support.
- Extended the OpenAdmin REST API with matching endpoints for Swap, Services > Podman, Backups, and User Export.
- Added autocompletion for all opencli scripts.
- Added default sorting by size for table on Disk Usage Explorer module.
- Added auto-installer and manager pages for SofaWiki and Flarum.

### 🐛 Bug Fixes
- Fixed duplicate rows in *OpenAdmin > Services > Podman*'s images table caused by shared-store images being listed twice.
- Fixed a layout bug on the OpenAdmin Users list page.
