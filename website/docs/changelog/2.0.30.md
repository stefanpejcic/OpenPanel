### 🐛 Bug Fixes
- FTP: the first FTP account couldn't be created after sentinel stopped the idle FTP server, `/ftp/new` and the API now let `ftp-add` start it, and active connections show an empty list instead of a 503.
- Backups: WordPress and app backups created the `backups` folders as root in the account's files, so users couldn't delete them and the File Manager showed them as root. They now get the account's owner, and old root-owned `backups` folders are fixed on the next backup.
- New installations use PHP 8.5 as the default version for new users again, WordPress and some app installers fail on 8.6.
