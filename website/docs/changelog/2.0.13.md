### 💡 New
- OpenAdmin > Settings > OpenPanel > Display has a new *Applications shown on Dashboard* option to pick which apps show in the Websites section on the OpenPanel Dashboard, and in what order (for example `wordpress n8n nodejs python`). Saved as `applications_dashboard_items` under `[PANEL]` in `openpanel.config`, default is `websites wordpress autoinstaller`.
