### Polish
- OpenPanel UI is rewritten from Python to Go.
- Screenshots are no longer locally generated by OpenPanel UI, instead our hosted service `https://api.openpanel.com/screenshots/` is used instead and resulting images are saved locally on the server.
- Added `filemanager_files_per_page` setting to limit number of files shown per page in File Manager.
- Added captcha settings on *OpenAdmin > Settings > OpenPanel*.
- On *OpenPanel > Domains > SSL* certificate files can be be set instead of paths to ssl files.
- OpenAdmin build now contains static assets.
- Containers now auto-start on reboot.
- Main server IP is now reachable from user containers.
- Added table column sorting on pages in OpenPanel UI:
  /process-manager
  /wordpress
  /ftp
  /mysql
  /mysql/users
  /domains
  /emails
  /php/domains
  /cronjobs
  /server/waf
  /account/sessions
  /account/favorites
  /account/activity
  /account/login-history
- Removed support for excel tables on Email Import.
- Added an option to test SMTP logins on OpenAdmin > Settings > Notifications.
