### 🔒 Security
- OpenPanel > MCP: a read-only MCP token could create a new token with full access and revoke the account's other tokens through `POST /api/account/mcp`, `DELETE /api/account/mcp/{id}` or `/mcp` `tools/call`. Read-only tokens are now refused there, and `tools/call` checks the tool's method itself.
- OpenPanel: changing or resetting the password now revokes all MCP tokens of the account, and a reset through the email link also removes the account's passkeys, so credentials added by whoever had access don't survive the recovery. [#1311](https://github.com/stefanpejcic/OpenPanel/issues/1311)
- OpenPanel > Forgot password: the request form is rate limited per IP (`login_ratelimit`), uses the login captcha when one is set, sends at most one reset email per account every 5 minutes, and shows the same page whether the email has an account or not. The link is sent to the address stored on the account, not to what was typed in the form.
- OpenPanel > Passkeys: the login and registration challenge is kept server-side and can be used only once, and expires after 5 minutes. Session cookies are also rejected once they are older than the 5 hour session lifetime.
- OpenPanel API: with `twofa_enforce` on, JWT and MCP tokens of an account without 2FA can only reach the 2FA setup routes, the same as the web panel. [#1314](https://github.com/stefanpejcic/OpenPanel/issues/1314)
- OpenPanel API: `POST /api/login` accepts only `application/json` and no longer writes the browser's session cookie, so a form on another site can't log the user out of the panel.
- OpenPanel: changing the contact email logs out every other session of the account (through the API, every session), since password reset links go to that address. [#1310](https://github.com/stefanpejcic/OpenPanel/issues/1310)
- `opencli user-delete` removes the deleted account's MCP tokens and passkeys, they were left in the database. [#1313](https://github.com/stefanpejcic/OpenPanel/issues/1313)
- OpenPanel > File Manager: the download id of a URL download (wget) is checked to be one the panel created before it is used to find the download's status file, and the activity log entry uses the logged-in user.
- OpenPanel > Backups: the SSH key file in the backup settings is always read from the account's own `/var/www/html/`, a path elsewhere is refused when saving, and line breaks in setting values are refused.
- OpenPanel > Backups: WebDAV, S3, Azure and SSH destinations set by the user can no longer point at loopback, private or link-local addresses. Destinations managed by the admin still can.
- OpenPanel > Backups: reindexing caps the size of the file lists it saves and how many archive entries it keeps in memory, limits the WebDAV and SSH listing size, and stops after 6 hours.
- OpenPanel > Backups: a restored `crons.ini` goes through the same checks as the Cron Jobs editor, a restored job can't use `job-run`, `job-local`, `job-service-run`, `image=` or `network=`.
- OpenPanel > Backups: queued restores always run as the account that queued them.
- OpenPanel > File Manager: view, edit, download, copy and extract only read regular files, a fifo or device in the web root is refused instead of hanging the request, and view never reads more than `filemanager_view_size`.
- OpenPanel > File Manager: extracting an archive stops once it writes more than `filemanager_extract_max_size` MB (default 10240).
- OpenPanel: file operations on an account's volumes don't follow a symlink the account put in place of the volume folder, and `docker-data`, `crons.ini`, `backup.env`, `backup_restores.json` and `backup_files` can't be mounted into a custom container.
- OpenPanel > Site Managers: uninstalling a site, and recording or clearing what an installer created, no longer follows a symlink out of the account's web root.
- OpenPanel > Backup Wizard: a backup running for an account whose name contains yours (bob and bobby) no longer shows as yours and blocks your backups.
- `opencli files-fix_permissions` uses `chmod -h` where available, so a file replaced by a symlink while it runs can't change the permissions of the link's target.
- OpenPanel > Domains: .onion key paths must be files inside the account's own `/var/www/html/` in the API too, `..` is refused, and `opencli domains-add` copies the keys without following symlinks, so a key path can't make it copy another account's files.
- OpenPanel > Cron Jobs: editing a job runs the same checks as creating one, a command can't add its own `[job-run]` or `[job-local]` section, and the container has to be a plain name so "Run now" can't pass podman options.
- OpenPanel > Domains > Redirects: deleting a redirect removes only the redirect line the panel wrote, and redirect URLs can't contain spaces, quotes or `{...}` placeholders.
- OpenPanel API: domain ownership checks refuse values with spaces, line breaks or `..`, and the email, DNS and domains endpoints take only a plain domain name, so a catch-all address can't be set for another account's domain.
- OpenPanel > Emails > Import: importing respects the plan's mailbox limit, and mailboxes without a quota in the CSV get the plan's max quota like ones created by hand.
- OpenPanel > MySQL: the root password is written to `my.cnf` by the panel instead of `sed`, and quotes, backslashes and line breaks are refused since the password is also stored in `.env`.
- OpenPanel: values the panel writes to an account's `.env` can't contain quotes or line breaks, so they can't add lines like `USER_ID`.
- OpenPanel > DNS: zone files can't use `$INCLUDE` or `$GENERATE`, only `$TTL` and `$ORIGIN`.
- OpenPanel > Webmail: the dovecot master user has its own key in `/etc/openpanel/openpanel/dovecot_master.key` instead of the panel's `secret.key`, and unused autologin tokens are removed from the Roundcube container.
- OpenPanel > Git: each account's git storage is capped by `git_max_storage_mb` (default 2048) and `git_max_repos` (default 50), since git data is stored as root and doesn't count against the disk quota.
- OpenPanel > Git: remote repositories can't point at loopback, private or link-local addresses, git doesn't follow redirects, and clone and pull connect to the address that was checked.
- OpenPanel > Web Terminal: the terminal opens only in the account's own services and never on the server's main podman.
- OpenPanel > Docker: `/home/<user>/crons.ini` and the other files the panel trusts can't be mounted into a container by their absolute path either.
- OpenPanel > FTP: FTP paths can only contain letters, numbers, `.`, `_`, `-` and `/`, and `opencli ftp-path`, `ftp-add`, `ftp-password` and `ftp-delete` call the FTP container without `sh -c`, so a path can't run commands in the shared FTP container.
- OpenPanel > WAF: removed tags are checked against the CRS tag format, so they can't add Caddy or SecLang directives to the domain config, and when Caddy rejects a WAF change the previous config is put back.
- OpenPanel > PHP: the version in the php.ini and PHP options routes has to be a plain `8.3` style version, and file operations refuse `..` under `/home`, so one account can't read or write another account's php.ini.
- OpenPanel > MySQL, PostgreSQL, MongoDB: the panel no longer follows symlinks to `my.cnf` or to the database sockets in the account's home, and the PostgreSQL connection string quotes every value, so an account can't point the panel at another account's database server.
- OpenPanel > PostgreSQL, MongoDB > Import: the uploaded dump is streamed into the container from an opened file instead of `podman cp` by path, so a symlink swapped in can't copy another file into the container.
- OpenPanel > Emails > Migrate: the imapsync job folder is opened inside the account's own home, a symlink swapped in can't make the panel open another account's folder.
- OpenPanel > DNS: adding a record goes through the same `$INCLUDE`/`$GENERATE` check as every other zone write, also in the domains API, and zone files can't contain carriage returns.
- OpenPanel > Dynamic DNS: tokens have to be 16 to 64 letters and numbers (existing shorter custom tokens stop working and need a new one), the public update URL is rate limited per IP and compares tokens in constant time, and zone writes take the lock before truncating.
- OpenPanel: php.ini, PHP options, web server config and WAF rule requests are capped at 1 MB, and container and service names in podman and podman-compose calls are checked so they can't be read as options.
