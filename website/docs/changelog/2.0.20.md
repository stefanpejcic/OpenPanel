### 🐛 Bug Fixes
- OpenPanel > Node.js, Python, Ruby, Java and n8n applications on Nginx and OpenResty: a stopped application no longer keeps the web server from starting. Nginx now looks up the application's container on every request, so only that application's URLs return 502 while it is stopped and they work again as soon as it starts. Applications installed before this keep the old proxy until they are reinstalled. [#1267](https://github.com/stefanpejcic/OpenPanel/pull/1267)
