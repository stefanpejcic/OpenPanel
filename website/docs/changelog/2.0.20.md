### 🐛 Bug Fixes
- `opencli docker-backup` no longer fails random accounts with "error running archive-pre commands" when the account still has a `backup` container running: the leftover container is removed before the backup, and `files-list.sh` gives each run its own temp files so two runs can't collide on the backup_meta volume.
- OpenPanel > Node.js, Python, Ruby, Java and n8n applications on Nginx and OpenResty: a stopped application no longer keeps the web server from starting. Nginx now looks up the application's container on every request, so only that application's URLs return 502 while it is stopped and they work again as soon as it starts. Applications installed before this keep the old proxy until they are reinstalled. [#1267](https://github.com/stefanpejcic/OpenPanel/pull/1267)

### 💅 Polish
- `opencli sentinel` webhook notifications now include the server hostname and public IP in the title, so you can tell which server sent them.
