Released on October 31, 2026.

### 💡 New
- [LiteSpeed Enterprise](/docs/panel/webserver/webserver_type/#litespeed) as a webserver. It reads Apache style configuration and `.htaccess` files, runs PHP in its own LSPHP and has LSCache with the crawler turned on.
  - A new account starts on a 15-day trial license, and the user adds a serial number any time on **Web Server Config > Server Settings** in OpenPanel. LiteSpeed gives one trial per server IP.
  - `opencli user-litespeed <username> [status|serial <SERIAL>|trial]` shows or sets the license, and `opencli update --litespeed` updates its files.
  - LiteSpeed is offered on the OpenAdmin **Settings > Defaults** page, the Add User form and the OpenPanel setup wizard. Existing accounts get it with this update.
- OpenAdmin > Settings > Defaults: Percona can be set as the default database for new accounts, it runs as the account's mysql service with the Percona Server image, the same as switching to Percona in OpenPanel.
- OpenAdmin > Settings > Defaults: Varnish is a toggle and shows that it isn't recommended with LiteSpeed or OpenLiteSpeed, since they cache pages themselves.
- OpenAdmin > License: without a license key the page lists what Enterprise adds over the Community edition.
- OpenAdmin > Dashboard: the Cluster widget shows a server's problem on its own line, so the server names and stats don't move.
- [Multi-server clustering](/docs/admin/system/multi-server) (Enterprise): manage several OpenPanel servers from one OpenAdmin. Every server stays a complete install with its own users, domains, mail and DNS, so a server keeps working when the master is down.
  - Add a server with a one-time join code from **System > Multi-Server**, and switch between servers from the server name in the sidebar.
  - Tables show the rows of all servers with a **Server** column and filter, and search, notifications, dashboard stats, `/services` and the header resource usage cover all servers. Row actions and bulk actions run on the server the row belongs to.
  - Settings can be saved on the selected server or on all servers, and they go to all servers by default. Settings that must differ per server, like the domain, are never applied everywhere.
  - Sync OpenAdmin and OpenPanel settings from the master to chosen servers, or let a slave follow the master. Each sync takes a backup that can be rolled back.
  - Move an account between servers from the GUI, optionally live with the source suspended only for the final sync. Accounts of a reseller can bring the reseller along.
  - Promote a slave to master, and update a server from the **Servers** table.
  - Pause a slave to leave it out of lists and of settings applied to all servers, and resume it later.
  - Cluster events, like adding, pausing or syncing a server, moving an account or a server going offline, are written to Notifications.
  - A slave that doesn't answer within 10 seconds is left out of lists instead of slowing down the master.
- OpenAdmin > Dashboard: move widgets by dragging, set each one to 1/3, 2/3 or full width and collapse them. The layout is saved on the admin account. The quick action buttons in the header are removed.
- The install script has a new `--join-cluster` option: generate an install command on the master and the new server joins the cluster as a slave when the installation finishes, with settings synced.
- `opencli user-transfer` has new `--identity` and `--known-hosts` flags, so a transfer can use an SSH key and a pinned host key instead of a password.

- `opencli sentinel` warns once when the Enterprise license expires in 3 days or less, with a link to renew it.

### 🐛 Bug Fixes
- OpenAdmin: the Documentation panel on Dashboard, Notifications, Daily Summary, Multi-Server and Websites could not load its page.
- OpenAdmin > License: "License info: undefined" was shown before a license key was added.
- OpenAdmin > Services: **Restart on all servers** gave no feedback and failed silently, it now waits for every server and reports the result.
- OpenAdmin > Dashboard: without the Cluster widget, Tasks and the next widget were stretched to the height of two rows.
- Multi-server: a slave was reported offline after a single slow answer, it now takes three failed checks in a row.
- OpenAdmin > Services: restarting a service recreates only that container. It used to stop and start its dependencies too, so restarting OpenPanel also restarted the panel's MySQL and Redis and took several seconds longer.
- `opencli report` and **Generate report** on the License page no longer try to upload the report to support.openpanel.org, which no longer accepts them. They show the path to the report file to send to support, `--public`, `--link` and `--upload` are still accepted but don't upload.
- `opencli backup` no longer includes `/etc/openpanel/openadmin/cluster`, and `opencli server-migrate` doesn't copy it, so restoring or migrating a server can't clone a cluster master.
- `opencli admin new --super` works on cluster slaves, the `cluster_` accounts a master uses to log in there no longer count as the super admin.
- `opencli user-transfer` runs its final sync after the account is suspended and only then cuts over, and it unsuspends the source account if the transfer fails.
- Caddy no longer writes a "key not found in collection" WAF warning to syslog for almost every request (gigabytes a day on busy servers): the Caddyfile's default logger is set to `ERROR` and `coraza_rules.conf` to `SecDebugLogLevel 1`. WAF rule violations are still logged. Existing servers get both on update, followed by a Caddy restart.
- `opencli server-logrotate` limits the journald size to 1G when no `SystemMaxUse` is set, since container output is stored in the journal as well.
- `opencli server-logrotate` no longer makes the nightly logrotate run fail: the Caddy logs config dropped its `podman exec caddy` reload (not needed with `copytruncate`, and blocked inside logrotate.service), and `/etc/logrotate.d/lfd` is made not group-writable so logrotate stops skipping it.
- `opencli server-logrotate` adds `maxsize` to the distribution's `/etc/logrotate.d/rsyslog`, so syslog filled by container output is rotated once it passes `logrotate_size_limit` instead of growing for a whole week.
- `opencli docker-backup` no longer fails random accounts with "error running archive-pre commands" when the account still has a `backup` container running: the leftover container is removed before the backup, and `files-list.sh` gives each run its own temp files so two runs can't collide on the backup_meta volume.
- OpenPanel > Node.js, Python, Ruby, Java and n8n applications on Nginx and OpenResty: a stopped application no longer keeps the web server from starting. Nginx now looks up the application's container on every request, so only that application's URLs return 502 while it is stopped and they work again as soon as it starts. Applications installed before this keep the old proxy until they are reinstalled. [#1267](https://github.com/stefanpejcic/OpenPanel/pull/1267)

### 💅 Polish
- `opencli sentinel` webhook notifications now include the server hostname and public IP in the title, so you can tell which server sent them.
- OpenAdmin > Dashboard: Dashboard, Notifications, Daily Summary and License (Upgrade on Community) are tabs of one page. The Daily Summary has its own tab, marked when something needs attention.
- OpenAdmin > License & Support: licenses without a due date no longer show a warning that they were due on 0000-00-00.
- OpenAdmin > Dashboard: titles from the Latest News widget no longer show literal quotes and backslashes.
- `opencli sentinel` process alerts list the user and the full command of each top process.
- OpenAdmin > Server > Default Node page is removed, adding servers is now done from **System > Multi-Server**.
