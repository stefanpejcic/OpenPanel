### 💎 New Features
- **PHP 8.6**: new installations use PHP 8.6 as the default version for new users. On existing servers the update adds `php-fpm-8.6` (`openpanel/php-fpm:8.6`, or `shinsenter/php:8.6-fpm` for accounts still on shinsenter images) to every account that has PHP 8.5 and to the template for new users, and makes 8.6 the default for new users only where it was 8.5. ionCube and some PECL extensions (igbinary, redis, apcu...) are added to the 8.6 image as soon as they support it ([#874](https://github.com/stefanpejcic/OpenPanel/issues/874)).
- **User panel themes**: pick a theme for OpenPanel in OpenAdmin > Settings > OpenPanel > Display > Theme, or install one from **Available themes** there. A theme holds only the pages it changes, the rest come from the built-in templates. See [How to create and install themes](/docs/articles/dev-experience/openpanel-themes/).
- **Users can switch theme**: new `allow_user_theme` option under the theme picker, off by default. When it's on, users pick any installed theme for themselves (account menu at the bottom left, or the General Information widget on Saturn), the choice is saved per user in `/home/<context>/theme` and a theme that's gone or invalid falls back to the default one.
- Two new themes to install from OpenAdmin: [Saturn](https://github.com/stefanpejcic/saturn-openpanel-theme), a classic hosting panel look with a Tools dashboard, and [Modern](https://github.com/stefanpejcic/modern-openpanel-theme), the redesigned panel by Arshile Gogen.
- `opencli update --system`: when the server needs a reboot (newer kernel installed, or updated packages ask for it) a **Reboot required** notification goes to OpenAdmin > Notifications and email/webhook, before it was only a line in the update log. Debian servers without update-notifier are detected too.

### 🐛 Bug Fixes
- `opencli update --system` (also run on major updates): apt could hang on a config file or debconf question, it now runs without prompts and keeps the server's config files.
- `opencli update --system`: on Ubuntu 26.04 it tried to install `deborphan`, which isn't available there anymore, it's now skipped.
- `opencli update --system` on AlmaLinux/Rocky: package cleanup could remove podman, sshd and other packages nothing depends on (`package-cleanup --leaves --all`), it now only runs `dnf autoremove`. Old kernels are now removed with `dnf remove --oldinstallonly`.
- `opencli update --system` on Debian/Ubuntu: old kernel cleanup counted the `linux-generic`/`linux-image-amd64` meta package as a kernel and left modules and headers of removed kernels behind. It now never touches the running or newest kernel, keeps up to 2 besides the running one and purges image, modules and headers together.
