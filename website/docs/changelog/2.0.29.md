### 🐛 Bug Fixes
- `opencli email-setup-bg chown`: a mailbox named `..@domain` made it run `chown -R` on the whole `/var/mail`, so every mailbox on the server ended up owned by that account. Names that are empty, `.`, `..`, start with a dot or dash, or have characters outside `a-z A-Z 0-9 . _ % + -` are now refused, and `chown` runs without a shell ([#277](https://github.com/stefanpejcic/opencli/pull/277)).
- OpenAdmin > Emails > Queue: with tens of thousands of queued messages the page never loaded (postqueue output of 100+ MB parsed on every load and every row rendered with all its recipients). The queue is now read as it streams, cached for 30 seconds, and shown 100 messages per page with server-side search and a filter per queue (hold, deferred, active).
