### 💡 New
- OpenAdmin > Notifications shows severity, category, occurrence count and resolved time for each notification, can be filtered, and warns when Sentinel hasn't run in over 15 minutes. Notifications are now stored as JSON lines in `/var/log/openpanel/admin/notifications.log` (existing notifications are cleared on update).
- `opencli sentinel` sends *Resolved* messages when an alert clears, groups all alerts from one run into a single email/webhook, and skips checks while an OpenPanel update is running.
- `opencli update` has new flags to update service files from GitHub: `--wp`, `--ols`, `--apache`, `--clamav`, `--phpmyadmin`, `--postgres`, `--skeleton`, `--ssh`, `--varnish` and `--cron`.
- `opencli report --user <USERNAME>` adds that user's account info, domains, containers, config and logs to the report.
- OpenPanel > MySQL, PostgreSQL and PHP now suggest optimizations based on memory limits, data, usage and logs, and apply them in one click.
- OpenPanel > MongoDB > Running Queries is a new page, and MySQL and PostgreSQL > Running Queries can now kill a running query.
- OpenPanel > PostgreSQL and MongoDB > Databases can now export a database, like on MySQL.
- New email notifications for users: passkey added/removed, API token created/revoked, malware found, hourly email limit reached, SSL certificate problems, service stopped and email account at 90% of quota. Existing users get them turned on when updating.
- Security and disk usage notification emails were redesigned with more details (time, IP, country, browser, usage bars, tips) and an *Upgrade* section on Enterprise when an upsell plan is set.
- OpenPanel > Containers has checkboxes to select several containers and bulk actions to start, stop, restart, set the CPU, RAM or PIDs limit, or delete the ones you added yourself.
- Bulk actions on more OpenPanel pages: select rows with the new checkbox column and pick an action from the bar at the bottom. Domains (suspend, unsuspend, change PHP version, redirect to a URL or remove the redirect, enable or disable WAF, delete), PHP > Domains (change version, reset to default), WAF (enable, disable), WordPress (update, backup, detach, uninstall), MySQL, PostgreSQL and MongoDB databases (export to a folder, optimize and repair on MySQL, assign or remove a user, delete) and users (change password, add to or remove from a database, delete), Cron Jobs (run now, change schedule or container, no-overlap on or off, delete), FTP (change password or path, delete), Emails (suspend or unsuspend incoming and outgoing, change quota or password, delete), Aliases (add destination, delete), Running Queries on MySQL, PostgreSQL and MongoDB (kill), Process Manager (kill), DNS Zone Editor (delete records, update TTL), Malware Scanner quarantine (restore, mark safe, delete), Remote MySQL (remove access), MCP tokens (revoke), Favorites (delete) and Active Sessions (terminate). Actions only show when the plan has the feature.
- Bulk actions in OpenAdmin: Users (suspend, unsuspend, change plan, password, email or IP, disable 2FA, generate a backup, delete), a user's Services tab (start, stop, restart, set the CPU, RAM or PIDs limit), Domains (change PHP version from the installed ones, enable or disable HSTS and WAF, suspend, unsuspend, delete), Services (start, stop, restart), Process Manager and Tasks (kill), Resellers and Administrators (suspend, unsuspend, delete), Plans (update one limit on many plans, delete unused plans), Email Accounts (change password, set or remove quota, restrict or allow sending and receiving, delete), Scheduled Actions cron jobs (change schedule, disable, logging on or off), Notifications (mark as read, delete), System Backups (delete), WAF rule sets (enable, disable) and Locales (install, update, delete).
- [Cron Jobs UX Suggestion #1155](https://github.com/stefanpejcic/OpenPanel/discussions/1155)
- OpenPanel > WordPress installs now add high-performance database keys (the ones from the Index WP MySQL For Speed plugin) to the new database, without installing the plugin.

### Polish
- OpenPanel > Account > Notifications shows each event as a card with a switch, description and docs link.
- OpenPanel > Cron Jobs is split into **Cron Jobs**, **File Editor** and **Logs** tabs, and Server Info into **Server**, **Hosting Plan** and **Panel** tabs.
- OpenPanel > PHP Default Version, Web Server Type, MySQL Server Type and Account > Language pages now use cards like the onboarding wizard. Percona can now be picked on MySQL > Server Type.
- OpenPanel > Containers > Software Versions lists image tags from Docker Hub in a searchable dropdown.
- OpenPanel > MySQL > Databases *Optimize* and *Repair* now show the tables and ask for confirmation first.
- `opencli report` now starts with a list of detected problems and collects much more system, network and container info.
- `opencli sentinel` alerts are more detailed, no longer email about issues it fixed on its own, and load/CPU/RAM alerts ignore short spikes.
- ionCube loader and wp-cli are now set up automatically on new installations.

### 🐛 Bug Fixes
- OpenPanel > Cron Jobs stops the cron service when no job is enabled, instead of leaving it restarting in a loop and filling its log.
- OpenAdmin > Users showed an error when suspending a user without domains, even though the user was suspended.
- OpenAdmin > Domains no longer accepts a PHP version that the domain owner doesn't have installed.
- OpenAdmin > a user's Services tab showed successful start, stop and restart actions as errors.
- OpenPanel > DNS Zone Editor no longer merges a new record into the last line of a zone file that doesn't end with a newline.
- OpenPanel > Malware Scanner > Quarantine updates right after a file is marked as safe, instead of showing it for up to 30 seconds.
- Fixed SQL injection in MySQL privileges when assigning a user to a database.
- `opencli report` no longer includes passwords, secrets or keys, and reports are readable by root only.
- Fixed MySQL, PostgreSQL and MongoDB imports (`.sql.gz` files and MongoDB imports failed).
- OpenPanel > MySQL > Server Type no longer wipes database data when the current type is submitted again.
- OpenPanel > PHP > Options now saves unticked On/Off options as `Off` instead of removing them.
- User notification emails showed raw HTML tags and linked to OpenAdmin.
- The monthly OWASP CRS update cron called a non-existent command, so rules were never updated.
- OpenAdmin > Server > Scheduled Actions broke the `opencli sentinel` cron jobs on save.
- `opencli update --cli` no longer deletes `/usr/local/opencli` before the download succeeds.
- `opencli update --translations` now finds locales with region codes (sr-rs, pt-br, zh-cn...).
- `opencli sentinel` emails now work with OpenAdmin basic auth enabled, and webhooks send valid JSON.
- `opencli license` now accepts `lifetime-` license keys.
