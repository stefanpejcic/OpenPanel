Not yet released.

### 💡 New
- OpenAdmin > Notifications now shows the severity (Critical, Warning, Info) and category of each notification, how many times an alert was detected, and when it was resolved, and can be filtered by status, severity and category.
- Notifications are now stored as one JSON object per line in `/var/log/openpanel/admin/notifications.log`, and `GET /api/notifications` returns them as objects with a `line_number` for the read/delete endpoints. Existing notifications are cleared when updating to 2.0.12.
- Sentinel emails now show each notification with its severity.
- `opencli sentinel` now marks an alert as resolved and sends a *Resolved* message by email/webhook when it's no longer detected.
- `opencli sentinel` now sends all alerts from one run as a single email and webhook.
- `opencli sentinel` skips its checks while an OpenPanel update is running, instead of alerting about and recreating containers the update is restarting.
- OpenAdmin > Server > Scheduled Actions now shows a description for every default OpenPanel cron job.
- OpenAdmin > Notifications now shows when Sentinel last ran its checks, and warns when it hasn't run in over 15 minutes.
- `opencli update` has new flags to update service files from GitHub: `--wp`, `--ols`, `--apache`, `--clamav`, `--phpmyadmin`, `--postgres`, `--skeleton`, `--ssh`, `--varnish` and `--cron` (`--clamav` and `--phpmyadmin` also recreate their running container with a new image).
- `opencli report --user <USERNAME>` adds that user's account info, domains, containers, config and container logs to the report.
- OpenPanel > MongoDB > Running Queries is a new page that lists operations running on the user's MongoDB server and lets them kill a slow one. Also available from the dashboard, search and the classic menu (*Show Processes*).
- OpenPanel > MySQL > Configuration now suggests optimizations based on the service's memory limit, your data, usage counters, connections and error log, and applies them in one click. Works for both MySQL and MariaDB, also available as `GET /api/mysql/configuration/recommendations`.
- OpenPanel > PHP > Options now suggests optimizations for each PHP version, based on the PHP service memory limit, the domains and WordPress sites using that version, the current options and the PHP-FPM log. Also available as `GET /api/php/{version}/options/recommendations`.
- OpenPanel > PostgreSQL > Configuration now suggests optimizations the same way as MySQL, based on the service's memory and CPU limits, data size, statistics, connections and log. Also available as `GET /api/postgresql/configuration/recommendations`.
- OpenPanel > PostgreSQL > Databases and MongoDB > Databases can now export a database, to the browser or to a folder under `/var/www/html`, like on MySQL. PostgreSQL exports as `.sql` or `.sql.gz`, MongoDB as `.archive` or `.archive.gz`.
- OpenPanel > MySQL > Running Queries and PostgreSQL > Running Queries can now kill a running query. The connection stays open, and every kill is recorded in the user's activity log. The API has matching `POST /api/mysql/processlist/{id}/kill` and `POST /api/postgresql/processlist/{pid}/kill` endpoints.
- `opencli email-usage <USERNAME|--all>` refreshes the cached email accounts and quota usage file of a user or all users.
- `opencli email-usage` emails users with `notify_email_quota_limit` enabled when an email account reaches 90% of its quota.
- Security notification emails (login, password, email address, 2FA, passkey and preferences changes) now show the time, IP address, country with its flag, browser and operating system in a table, and what to do if it wasn't the user. Login emails also say how the user logged in, email address changes show the old and new address, and preference changes list the alerts that were turned off.
- New email notifications, each with its own switch on OpenPanel > Account > Notifications: **Passkey added or removed** (split from the 2FA alert, and removals are now reported too), **API token created or revoked** for AI Assistant (MCP) tokens, **Malware found** when the scheduled scan quarantines files, **Hourly email limit reached**, **SSL certificate problem** when an AutoSSL certificate fails to renew or any certificate is about to expire, and **Service stopped** when Sentinel had to restart a user's service or it ran out of memory. Existing users get the new options turned on when updating to 2.0.12.
- `opencli domains-ssl --notify` emails users about AutoSSL certificates with 7 days or less left (renewal failing) and any certificate with 1 day or less left, once per certificate. It runs daily from cron.
- `opencli email-ratelimit --notify` emails users whose account reached the hourly email limit, at most once a day. It runs every 30 minutes from cron.
- Disk space and mailbox emails now show usage bars colored like Sentinel alerts (disk and inodes, or each full mailbox), the time of the check and tips on freeing up space. On Enterprise, when the plan's upsell plan raises the limit that is running out, they also include an *Upgrade* section with a button to Dashboard > Upgrade.

### Polish
- OpenPanel > Account > Notifications shows each event as a card with a switch, a description and a *Learn more* link to the docs, and extra options only show once their alert is on. The unused AutoSSL and SSL options are removed.
- Emails for logins from an IP address already in the login history are now off by default for new users (`notify_account_login_for_known_netblock=0`).
- OpenPanel > Cron Jobs is split into **Cron Jobs**, **File Editor** and **Logs** tabs (`/cronjobs`, `/cronjobs/editor`, `/cronjobs/logs`), replacing the *Switch to File Editor* button and the inline log panel. A job's *Logs* button opens the Logs tab filtered to that job.
- OpenPanel > Server Info is split into **Server**, **Hosting Plan** and **Panel** tabs (`#server`, `#plan`, `#panel`), and the enabled features list wraps onto multiple lines.
- OpenPanel > Containers > Software Versions now lists the service's image tags from Docker Hub in a searchable dropdown where you can also type a custom tag, links to the image's tags on Docker Hub, and no longer lists the internal cron, backup and docker-proxy services.
- OpenPanel > PHP > Default Version now shows each installed version as a card with its support status, like the onboarding wizard.
- OpenPanel > Web Server Type and MySQL > Server Type now show each option as a card with its logo and description, like the onboarding wizard, only list servers available on the account and explain what has to be removed first. Percona can now be picked on MySQL > Server Type, not only in the onboarding wizard.
- OpenPanel > Account > Language now shows a card for each language with its flag, native and English name and a search box, and the login page language picker shows the current language with flags, names and search.
- OpenPanel > MySQL > Databases *Optimize* and *Repair* now open a list of the tables with their engine, size and unused space and only run when you confirm. Results are shown as OK, Rebuilt, Not needed or Failed, and Optimize shows how much space it freed. Views are skipped.
- `opencli user-list` help now lists the `--quota` flag.
- `opencli report` now starts with a list of detected problems and also collects kernel and virtualization info, inode usage, top processes, OOM kills, failed systemd units, listening ports, DNS and outbound connection tests, container resource usage, per-user container status and logs of the OpenPanel, Caddy, MariaDB and Redis containers.
- `opencli sentinel` service alerts now say what failed, what Sentinel tried, which command to check it with, and include the last log lines.
- `opencli sentinel` no longer emails about things it already fixed on its own (restarted containers and services, cleared SWAP), they are logged as read entries in OpenAdmin > Notifications.
- `opencli sentinel` load, CPU and RAM alerts are only sent after 2 checks in a row over the threshold, and CPU is measured over 1 second, so short spikes no longer trigger alerts.
- Version and Port columns are removed from `OpenAdmin > Services` table.
- ioncube loader extensions are now auto added for new installations and php versions.
- wp-cli.phar is now auto-updated for new installations.
- `opencli sentinel` now marks UNREAD notifications as READ once the issue they reported is resolved (service back up, usage below threshold, DNS resolving, etc.).
- `opencli admin port <PORT> --no-restart` no longer prints the firewall warning twice.
- `opencli domains-varnish` help examples are fixed and the output typo "ontainer" is corrected.
- `opencli email-server` help now lists the `uninstall` command, and typos in its uninstall and stop messages are fixed.

### 🐛 Bug Fixes
- Notification emails to users showed HTML tags like `<b>` and `<br>` as plain text, and the 2FA, passkey, disk space and mailbox emails used the admin Sentinel template with a link to OpenAdmin. All user emails are now plain text in the same template as the password change email.
- OpenPanel > Containers > Software Versions and `PATCH /api/containers/{service}/image` now validate the new image tag before saving it to `.env`.
- OpenPanel > PHP > Extensions showed ionCube Loader as not installed even when it was loaded, and offered to install it. It's provided by OpenPanel, so it now shows as enabled or disabled with *Provided by OpenPanel* and can't be installed or toggled from the page.
- The onboarding wizard described end-of-life PHP versions as *Fully supported*, because their status label "Unsupported" contains the word "supported".
- OpenPanel > MySQL > Import of `.sql.gz` files now works, the file was passed to `mysql` without being decompressed.
- OpenPanel > MySQL > Server Type no longer wipes the database data when the type already in use is submitted again.
- OpenPanel on Percona is now shown as Percona instead of MySQL on the Server Type page and in the onboarding wizard.
- The login page showed the wrong flag for Nepali, Serbian and Swedish (the flags of Niger, Suriname and El Salvador).
- The login page and Account > Language now ignore language codes that are not available, the login page stored any posted value in the session.
- OpenPanel > PHP > Options now saves an unticked On/Off option as `Off` (or `0`), it used to remove the line so PHP fell back to its built-in default, which is On for `display_errors`.
- OpenPanel > PostgreSQL and MongoDB pages now show the service status widget in the header like MySQL.
- OpenPanel > MySQL table sizes and unused space showed as 0 on MySQL 8+, the values were read as the wrong number type.
- OpenPanel > MongoDB > Import now works, it failed for every file because `mongorestore` ran without credentials and with an invalid rename pattern.
- OpenPanel > PostgreSQL > Import of `.sql.gz` files now works, the file was passed to `psql` without being decompressed.
- OpenPanel > MySQL privileges are now checked against the list of allowed privileges when assigning a user to a database, in the Database Wizard and in `POST /api/mysql/grants`, so a crafted request can no longer inject SQL into the `GRANT` statement.
- OpenPanel > MySQL > Running Queries now shows the ID and Time columns, they were always empty.
- OpenPanel > PostgreSQL > Running Queries now shows the Pid column, which was always empty, and no longer breaks rows for queries that contain a `|`.
- OpenPanel > MySQL > Configuration *read the documentation* link no longer points to a missing page, and the Cron Jobs and Backup destination docs links go straight to the current pages.
- `opencli report` no longer includes MariaDB login files or passwords, secrets and keys from config files, and reports are now readable by root only.
- `opencli report` no longer refuses to run while an OpenPanel install or update holds its lock.
- `opencli report` now lists the OpenPanel stack correctly (`podman-compose ps` ran outside `/root`) and no longer cuts off slow commands after 3 seconds.
- `opencli user-rename` notification title typo "User accountu username changed" is fixed.
- `opencli sentinel` emails now work when OpenAdmin basic auth is enabled.
- `opencli sentinel` no longer sends OOM alerts to the webhook twice, and webhooks with container logs now send valid JSON.
- The monthly OWASP CRS update cron now runs `opencli waf update`, the default cron called `opencli waf-update` which doesn't exist, so the rules were never updated. Existing servers are fixed when updating to 2.0.12.
- OpenAdmin > Server > Scheduled Actions no longer breaks the `opencli sentinel` cron jobs on save (they were rewritten to the removed `notifications.sh` script), and already affected lines are fixed on the next save or when updating to 2.0.12.
- OpenAdmin > Server > Scheduled Actions *Learn more* links now work, and each job links to its OpenCLI docs page.
- `opencli port` and `opencli proxy` now respect the `--no-restart` flag.
- `opencli license` now accepts `lifetime-` license keys.
- `opencli files-fix_permissions --all` now works with the current `opencli user-list --json` format.
- `opencli update --cli` no longer deletes `/usr/local/opencli` before downloading, the old scripts are kept if the download fails or GitHub is unreachable.
- `opencli error` now reads OpenPanel logs with `podman logs` instead of `docker`.
- `opencli ftp-connections <USERNAME>` now shows only connections of FTP accounts on domains owned by that user.
- `opencli plan-usage --json` now returns valid JSON (`[]` when no users are on the plan).
- `opencli websites-vulnerability --all` now shows the correct number of plugins and themes in the summary.
- `opencli sentinel` RAM check now skips correctly while a *High Memory Usage!* notification is unread.
