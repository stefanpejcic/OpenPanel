### 💡 New
- `opencli websites-secure` has two new WP Manager rules: `wp_manager_disable_wp_admin` blocks /wp-admin and `wp_manager_mitigate_spam_logins` drops login and comment POSTs without a same-site Referer. Also available in WP Manager > Security. [#1167](https://github.com/stefanpejcic/OpenPanel/issues/1167)
- OpenPanel > Malware Scanner: new *Scan Logs* page with past scans and what they found, for scans started from the panel, the API and the automatic `opencli files-malware_scan` cron scans. Also available as `GET /api/malware-scanner/logs`.

### 💅 Polish
- OpenPanel > File Manager: UX improvements to the File Manager page.
- OpenPanel > Malware Scanner: the scan spinner now shows next to the number of files scanned, and a scan stops when the page is closed instead of running on in the background.
- Cloudflare-only setting for admins and cloudflare module for users [#1165](https://github.com/stefanpejcic/OpenPanel/discussions/1165)

### 🐛 Bug Fixes
- [Matomo auto install fails if domain not pointed to the server #1169](https://github.com/stefanpejcic/OpenPanel/issues/1169)
- `opencli sentinel` no longer clears SWAP on every run when it fills right back up. It now clears SWAP at most once a day and sends a single *High SWAP usage!* alert instead. [#1172](https://github.com/stefanpejcic/OpenPanel/issues/1172)
- `opencli update` no longer fails with *Update process is already running* after a previous update: the restarted OpenPanel container kept the update lock open forever. Updates are now stopped after 30 minutes and older locks are deleted.
- `opencli sentinel` no longer skips all checks indefinitely because of a stale update lock.
- `opencli update` now updates OpenAdmin again: `opencli update --check` and other nested `opencli update` calls made during an update re-ran the update instead of doing their own job.
- `opencli websites-secure <domain> --list-active-rules` no longer freezes, and active rules are no longer listed twice. [#1167](https://github.com/stefanpejcic/OpenPanel/issues/1167)
