### 💎 New Features
- [Hide the CPU/Memory #1330](https://github.com/stefanpejcic/OpenPanel/issues/1330)
- WHMCS: the [OpenPanel WHMCS module](https://github.com/stefanpejcic/openpanel-whmcs-module) can sell reseller accounts. Products of type Reseller Account create an OpenAdmin reseller on the chosen reseller package, and support suspend, unsuspend, terminate, package and password changes, single sign-on to OpenAdmin and the daily disk usage import. Resellers can also add their own OpenAdmin login to the module in their own WHMCS to sell to their customers.
- OpenAdmin > API: `GET /api/settings/resellers/{username}` returns one reseller, and `POST /api/settings/resellers/{username}/login` gives administrators a one-time OpenAdmin login link for a reseller without their password.
- OpenAdmin > API: `GET /api/usage/disk` is available to resellers and returns only the accounts they own.
- OpenAdmin > Resellers: deleting a reseller asks for confirmation, and the new **Delete with accounts** action also deletes every account the reseller owns. A plain delete moves those accounts to the administrator instead of leaving them with an owner that no longer exists. The API takes `"with_users": true` and opencli `opencli admin delete <user> --with-users`.

### 💅 Polish
- [OpenPanel: user panel redesign #1322](https://github.com/stefanpejcic/OpenPanel/pull/1322)
- OpenPanel > Dashboard: new **Overview** view (now the default) with plan usage, your newest websites, resource usage and quick actions, and a **Tools** view with every feature, a tool finder and the layout lock and reset buttons.
- OpenPanel: refreshed light and dark themes, a smaller header logo, and the AI Assistant button and panel styled for dark mode.
- OpenPanel: disabling a service, 2FA or other settings that stop something now asks for confirmation first.
- OpenPanel > Getting Started Tour: updated for the new dashboard and pages.

### 🐛 Bug Fixes
- [Hide the CPU/Memory #1330](https://github.com/stefanpejcic/OpenPanel/issues/1330)
- [Logout URL doesn't save #1332](https://github.com/stefanpejcic/OpenPanel/issues/1332)
- OpenAdmin > Reseller packages: saving a package or moving a reseller to another one no longer removes the user plans the reseller created themselves from their allowed plans, and a package with no user plans no longer locks the reseller out of all of them.
- OpenAdmin > Resellers: suspending a reseller suspends the accounts they own again, previously the confirmation prompt of `opencli user-suspend` cancelled every one of them. Unsuspending wakes only the accounts suspended along with the reseller, so accounts the reseller suspended themselves stay suspended.
- OpenAdmin > Security: suspended administrators and resellers can no longer get an API token, tokens issued before the suspension stop working, and their open OpenAdmin sessions end.
- OpenAdmin: error messages from opencli no longer show terminal color codes like `[0;31m`.
- opencli: `opencli admin delete` exits with an error when the user doesn't exist or has the admin role, instead of reporting success.
- OpenPanel > Services: the Services page (`/services`) lists the account's services again instead of showing "invalid service name".
- OpenPanel > FTP: uploads, downloads and listings no longer fail with the FTP server sending its internal `172.20.0.6` address for passive mode when the public IP lookup failed on start. The lookup retries for about a minute, the IP is saved as `FTP_PASV_ADDRESS` in `/root/.env` on install, and sentinel updates it and recreates the FTP container on boot if the server IP changed.
- OpenPanel > phpMyAdmin: auto-login no longer loops with "too many redirects" on accounts created since the `.env` permission change, `.env` is now readable by phpMyAdmin (mode 640, group www-data) and still not by other accounts. The update fixes existing accounts.

### 🔒 Security
- [SSRF deny-list bypass in safenet.IsPublicIP via IPv6-embedded internal addresses (file-manager "Download from URL")](https://github.com/stefanpejcic/OpenPanel/security/advisories/GHSA-mfhh-p638-rmc6): URL downloads in the File Manager, git remotes and email migration now also refuse IPv6 addresses that carry or route to an internal IPv4 address (NAT64 `64:ff9b::/96`, 6to4 `2002::/16`, Teredo `2001::/32`, IPv4-compatible `::/96`, site-local `fec0::/10`) and reserved IPv4 ranges.
