### 🐛 Bug Fixes
- `opencli user-list --quota` works again, it called a command that doesn't exist. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- `opencli plan-list --json` now returns one valid JSON array with every column under its own name, including `upsell_plan_id` and `upsell_url`, instead of an array per plan with the limits under the wrong keys. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- `opencli admin new` and `opencli admin password` now accept the same passwords as OpenAdmin (6-30 characters without spaces), so resellers created from the API with a symbol in the password no longer fail. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- `opencli ftp-add` now accepts a `.` before the `@`, like the other `ftp-*` commands and the panel. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- Creating the first user on a fresh install no longer fails with `Can't connect to server on '127.0.0.1'`. The installer edited `/root/docker-compose.yml` after MySQL was already up, so the first `opencli user-add` recreated MySQL in the middle of its insert. [#1246](https://github.com/stefanpejcic/OpenPanel/pull/1246)
- `opencli domains-add` no longer leaves Apache or PHP-FPM down on a user's first domain. Both start at the same time, and the one that lost the race to create the user's network gave up instead of trying again. [#245](https://github.com/stefanpejcic/opencli/pull/245)
- `opencli api list` works again on current OpenAdmin, it now lists all endpoints with their access and a curl example for the server's OpenAdmin URL, from the same source as the API docs on *OpenAdmin > Settings > API*. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- `opencli domain ip` no longer exits with an error and no message when the server is already accessed by IP. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli license verify` only checks the key and no longer restarts OpenAdmin and OpenPanel. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli license key --json` and `opencli license info --json` now always print valid JSON, and *OpenAdmin > License* no longer shows "No License Key" as the key when none is set. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli user-quota <username>` now shows an error instead of silently doing nothing, quotas are set with `opencli user-quota --update <username>`. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli email-quotas` fixes mail permissions again, it detected every domain as `mail` and skipped them all. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli email-server view` prints the mail to stdout so it can be saved to a file, and `opencli email-server status` works from cron and the panel. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- Deleting a plan from the OpenAdmin API (`DELETE /api/plans/{id}`) actually deletes it, it was passing the id where the plan name was expected. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- Editing a plan whose name has a space now correctly detects which limits changed and need to be applied to users. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli ftp-list <username>` now finds FTP accounts for users whose username differs from the context, so `opencli files-fix_permissions` fixes them as well. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli php-default` escapes the username in its database query. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- Deleting a domain also removes its access logs directory and DKIM keys. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli user-rename` exits with an error if the database update fails and no longer moves user files in that case, and `opencli user-delete` removes the user's settings for renamed users. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli plan-usage --json` now returns one valid JSON array instead of one array per user. [#236](https://github.com/stefanpejcic/opencli/pull/236)
- `opencli plan-delete` reports "not found" and exits with an error for a plan that doesn't exist instead of reporting it as deleted, and `--json` lists the plan's users as a valid JSON array. [#236](https://github.com/stefanpejcic/opencli/pull/236)
- `opencli config update`, `opencli port set` and `opencli proxy set` now exit with an error on an unknown parameter or invalid value, so scripts and the API no longer treat them as successful. [#236](https://github.com/stefanpejcic/opencli/pull/236)
- `opencli domains-add`, `opencli domain` and `opencli php-domain` no longer leave `nohup.out` and `nohup.err` files in the directory they were run from. [#236](https://github.com/stefanpejcic/opencli/pull/236)
- OpenPanel > Backups: downloading or restoring a backup only works for the account's own archives, so with a shared admin-managed destination an account can no longer download or restore another account's backup by its file name. [#1236](https://github.com/stefanpejcic/OpenPanel/pull/1236)
- `opencli domains-varnish` no longer overwrites its `--json` flag with the WordPress sites list, which broke the rest of the command. [#239](https://github.com/stefanpejcic/opencli/pull/239)
- `opencli admin update` exits with an error when a value is invalid (for example a non-numeric `--max_accounts`) instead of reporting the reseller as updated. [#239](https://github.com/stefanpejcic/opencli/pull/239)
- `opencli admin delete` escapes the username in its database query. [#239](https://github.com/stefanpejcic/opencli/pull/239)
- `opencli error` also prints the last log line, the one that has the error ID. [#239](https://github.com/stefanpejcic/opencli/pull/239)
- `opencli user-change_plan` no longer leaves `TOTAL_CPU=` empty in the user's `.env`, or `TOTAL_RAM=` when the plan's RAM ends in `G`. [#227](https://github.com/stefanpejcic/opencli/pull/227)
- `opencli user-delete` clears the user's failed systemd units, so the server no longer shows as degraded after deleting a user. [#227](https://github.com/stefanpejcic/opencli/pull/227)
- OpenAdmin > Users and `GET /api/users/{username}` match a suspended user by the exact username, so they no longer show a different customer's account whose name only contains it. [#8](https://github.com/stefanpejcic/openadmin/pull/8)
- OpenAdmin > Web Terminal: commands that keep printing output, like `opencli update` or a backup, are no longer killed after 5 minutes without typing, and the terminal closes as soon as the shell exits. [#11](https://github.com/stefanpejcic/openadmin/pull/11)
- OpenAdmin > Web Terminal: open terminals are closed when the admin logs out, is suspended or deleted, or when `/root/disable_openadmin_terminal_ui` is created, and opening and closing a terminal is recorded in the admin's activity log. [#14](https://github.com/stefanpejcic/openadmin/pull/14)
- `opencli domains-dns delete` removes the zone from BIND's configuration and reloads it, so BIND stops serving the deleted zone and the next reload no longer fails on its missing file. [#237](https://github.com/stefanpejcic/opencli/pull/237)
- `opencli user-delete` removes the user's systemd slice settings, so a new account that gets the same user ID doesn't inherit them. [#237](https://github.com/stefanpejcic/opencli/pull/237)
- OpenPanel > Docker: a volume's `./folder` source is refused when it's a symlink that points outside the account's home, so a container can no longer be given the host's or another account's files. [#1238](https://github.com/stefanpejcic/OpenPanel/pull/1238)
- OpenPanel > Applications: detecting the startup file of a Git repository refuses repositories on internal addresses (localhost, private networks, the cloud metadata address), so it can't be used to reach internal services. [#1237](https://github.com/stefanpejcic/OpenPanel/pull/1237)
- OpenPanel > Login: a username that isn't found is only reported as suspended when it is exactly a suspended account's name, instead of any suspended account that contains it (or any at all for `%`). [#1232](https://github.com/stefanpejcic/OpenPanel/pull/1232)
- `opencli user-unsuspend` and `opencli user-delete` act on the exact suspended user, unsuspending `john` could rename suspended `bjohn` and deleting `john` could delete `bjohn`. `docker`, `waf`, `user-add` and `user-report` use the same exact match. [#226](https://github.com/stefanpejcic/opencli/pull/226)
- `opencli user-add` makes each account's `my.cnf`, `.env` and `backup.env` readable only by the account, they were readable by other accounts and hold the account's MySQL root password and other credentials. Existing accounts keep their current permissions. [#242](https://github.com/stefanpejcic/opencli/pull/242)
- `opencli locale` runs the translations installer from a pinned, reviewed commit and checks its SHA-256 before running it, instead of whatever is on the repository's `main` branch. [#238](https://github.com/stefanpejcic/opencli/pull/238)
- OpenAdmin > Web Terminal: the websocket only accepts connections from OpenAdmin's own address, demo mode blocks the terminal, the disable flag also blocks container terminals, an unknown username returns 404 instead of opening a shell in a root container, and a `?cmd=` link opened before logging in is typed but not run. [#15](https://github.com/stefanpejcic/openadmin/pull/15)
- OpenAdmin: `https://<hostname>` on port 443 works after an SSL certificate is issued for the hostname, it returned `Client sent an HTTP request to an HTTPS server`. [#9](https://github.com/stefanpejcic/openadmin/pull/9)
- Installer: AlmaLinux and other EL servers with SELinux enforcing install correctly, SELinux no longer blocks the containers from their files, and the SSH and Cron services can be managed from OpenAdmin. [#1242](https://github.com/stefanpejcic/OpenPanel/pull/1242)
