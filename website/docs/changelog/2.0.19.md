### 💡 New
- `opencli docker-backup --account=<username>` backs up a single account right away, with the same checks as the scheduled run. Only one backup of an account runs at a time, so a scheduled run skips an account that is already being backed up. [#253](https://github.com/stefanpejcic/opencli/pull/253)
- `opencli docker-backup` only backs up accounts whose backups the hosting provider manages, the ones with an `admin.backups` marker, and skips accounts that manage their own backups. [#254](https://github.com/stefanpejcic/opencli/pull/254)
- OpenPanel > File Manager and Trash: Shift+click selects every row from the last clicked one, following the current sort, and Ctrl/Cmd+Shift+click adds the range to the selection. [#1276](https://github.com/stefanpejcic/OpenPanel/pull/1276)
