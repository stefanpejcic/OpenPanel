### 🐛 Bug Fixes
- `opencli user-list --quota` works again, it called a command that doesn't exist. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- `opencli plan-list --json` now returns one valid JSON array with every column under its own name, including `upsell_plan_id` and `upsell_url`, instead of an array per plan with the limits under the wrong keys. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- `opencli admin new` and `opencli admin password` now accept the same passwords as OpenAdmin (6-30 characters without spaces), so resellers created from the API with a symbol in the password no longer fail. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- `opencli ftp-add` now accepts a `.` before the `@`, like the other `ftp-*` commands and the panel. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- Creating the first user on a fresh install no longer fails with `Can't connect to server on '127.0.0.1'`. The installer edited `/root/docker-compose.yml` after MySQL was already up, so the first `opencli user-add` recreated MySQL in the middle of its insert.
- `opencli domains-add` no longer leaves Apache or PHP-FPM down on a user's first domain. Both start at the same time, and the one that lost the race to create the user's network gave up instead of trying again.
### 💅 Polish
- `opencli --help` and tab completion now list `backup`, `docker-update`, `domains-cloudflare` and `files-malware_scan`, and no longer list the removed `patch`. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- `opencli user-quota`, `user-change_plan` and `user-unsuspend` show their actual flags in `opencli --help`, and scripts that had the wrong `# Script Name:` header were fixed. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
