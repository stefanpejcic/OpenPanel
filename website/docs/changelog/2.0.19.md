### 🐛 Bug Fixes
- `opencli user-list --quota` works again, it called a command that doesn't exist. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- `opencli plan-list --json` now returns one valid JSON array with every column under its own name, including `upsell_plan_id` and `upsell_url`, instead of an array per plan with the limits under the wrong keys. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- `opencli admin new` and `opencli admin password` now accept the same passwords as OpenAdmin (6-30 characters without spaces), so resellers created from the API with a symbol in the password no longer fail. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- `opencli ftp-add` now accepts a `.` before the `@`, like the other `ftp-*` commands and the panel. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- `opencli api list` works again on current OpenAdmin, it now lists all endpoints with their access and a curl example for the server's OpenAdmin URL, from the same source as the API docs on *OpenAdmin > Settings > API*. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- `opencli domain ip` no longer exits with an error and no message when the server is already accessed by IP. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli license verify` only checks the key and no longer restarts OpenAdmin and OpenPanel. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli license key --json` and `opencli license info --json` now always print valid JSON, and *OpenAdmin > License* no longer shows "No License Key" as the key when none is set. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli user-quota <username>` now shows an error instead of silently doing nothing, quotas are set with `opencli user-quota --update <username>`. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli email-quotas` fixes mail permissions again, it detected every domain as `mail` and skipped them all. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli email-server view` prints the mail to stdout so it can be saved to a file, and `opencli email-server status` works from cron and the panel. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- Deleting a plan from the OpenAdmin API (`DELETE /api/plans/{id}`) actually deletes it, it was passing the id where the plan name was expected. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- Editing a plan whose name has a space now correctly detects which limits changed and need to be applied to users. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli ftp-list <username>` now finds FTP accounts for users whose username differs from the context, so `opencli files-fix_permissions` fixes them as well. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli php-default` escapes the username in its database query. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- Deleting a domain also removes its access logs directory and DKIM keys. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli user-rename` exits with an error if the database update fails and no longer moves user files in that case, and `opencli user-delete` removes the user's settings for renamed users. [#241](https://github.com/stefanpejcic/opencli/issues/241)
- `opencli plan-usage --json` now returns one valid JSON array instead of one array per user. [#236](https://github.com/stefanpejcic/opencli/pull/236)
- `opencli plan-delete` reports "not found" and exits with an error for a plan that doesn't exist instead of reporting it as deleted, and `--json` lists the plan's users as a valid JSON array. [#236](https://github.com/stefanpejcic/opencli/pull/236)
- `opencli config update`, `opencli port set` and `opencli proxy set` now exit with an error on an unknown parameter or invalid value, so scripts and the API no longer treat them as successful. [#236](https://github.com/stefanpejcic/opencli/pull/236)
- `opencli domains-add`, `opencli domain` and `opencli php-domain` no longer leave `nohup.out` and `nohup.err` files in the directory they were run from. [#236](https://github.com/stefanpejcic/opencli/pull/236)
### 💅 Polish
- `opencli --help` and tab completion now list `backup`, `docker-update`, `domains-cloudflare` and `files-malware_scan`, and no longer list the removed `patch`. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
- `opencli user-quota`, `user-change_plan` and `user-unsuspend` show their actual flags in `opencli --help`, and scripts that had the wrong `# Script Name:` header were fixed. [#1235](https://github.com/stefanpejcic/OpenPanel/issues/1235)
