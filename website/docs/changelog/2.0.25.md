### 💎 New Features
- OpenPanel > Auto Installer: 32 new one-click Docker apps, each one tested on a domain: Open WebUI, Langflow, Excalidraw, Stirling PDF, NextChat, Grafana, AnythingLLM, NocoDB, LiteLLM, PocketBase, Meilisearch, Jellyfin, Joplin Server, Ghost, Flowise, Huginn, Metabase, Paperless-ngx, Gogs, RSSHub, IT-Tools, drawDB, Trilium Notes, CyberChef, changedetection.io, Qdrant, Umami, SearXNG, Actual Budget, Beszel, Typesense and Dashy.
- OpenPanel > Daily Summary: new Databases section with size, traffic, connections, failed logins, slow queries, deadlocks and errors for each database server.
- OpenAdmin > Daily Summary: new Backups section with that day's centrally configured account backup run (how long it took, largest backups, skipped runs) and a Busiest databases list, database problems are now shown under the account they belong to.

### 🐛 Bug Fixes
- `opencli domain set` now waits for the hostname's SSL certificate before configuring the mailserver, so IMAP/SMTP and Roundcube switch to the new domain instead of staying on the IP when the certificate was issued a few seconds after the command.
- `opencli domain set` and `opencli domain ip` now also point `/webmail` at `https://webmail.<hostname>` (or back to `http://IP:8080`), it kept sending users to the unencrypted IP address after the panel got a domain.
- `opencli email-server install` no longer asks to remove `/usr/local/mail/openmail` on a fresh server where that folder is empty, which aborted the install when run without a terminal.
- OpenAdmin > Onboarding: "Enable modules" is no longer marked done just because the Enterprise license or ImunifyAV install added their own modules, and OpenResty/LiteSpeed images now count for the "Download required Podman images" step.
- OpenPanel > Dashboard: the databases widget showed MySQL database names as a list of numbers instead of the name.
- OpenAdmin > Updates: checking for the latest version works again, it still asked usage-api.openpanel.org which is gone.
- Installer: installs the latest version from api.openpanel.com, it always fell back to the version hardcoded in the script, now the newer of the two is used.

### 💅 Polish
- OpenAdmin > Onboarding: new "Enable two-factor authentication" and "Schedule backups" steps, Community servers get an "Upgrade to Enterprise" step, and "Set up SMTP and notifications" is done only once both the SMTP server and the admin notification email are set.
- OpenPanel > Account: country flags next to the current and last login IP addresses, they follow the admin's IP flags setting.
- OpenAdmin > Daily Summary: alerts that differ only by IP address, like an admin logging in from new IPs, are merged into one row that lists the addresses.

### 🔒 Security
- Caddy image rebuilt on Caddy 2.11.9 with the latest Go and Alpine packages and newer `x/net`, `x/crypto` and `compress` than Caddy pins, the 2.0.25 update pulls the new image.
- `opencli update` now also updates the Caddy image on major version updates, and `opencli update --caddy` does it on demand. The new image has to validate the current Caddyfile before Caddy is recreated, so a failed download or an incompatible config leaves the running Caddy untouched.

Hardening from a review of the user panel by [@caesarmind](https://github.com/caesarmind) ([#1351](https://github.com/stefanpejcic/OpenPanel/pull/1351)):
- OpenPanel > Cron Jobs: editing a job, saving the raw crons file or running a job now checks the container is one of the account's own, so a job can no longer be pointed at the internal `docker-proxy` container that holds the account's Podman socket.
- OpenPanel > Domains: the live visitors endpoint now checks domain ownership, any logged-in user could read the recent visitor IPs of another account's domain.
- OpenPanel > File Manager: SVG files are downloaded instead of opened inline, a script inside an SVG could run with the viewer's panel session.
- OpenPanel > Auto Installer: the PHP app archive download and the git startup-file detection only connect to public addresses, on every redirect too, so they can't be used to reach internal services or the cloud metadata endpoint.
- OpenPanel > DokuWiki and CMS backups: the docroot and the backup folder are validated before they're used in shell commands inside the PHP container.
- OpenPanel > Docker: the container API now validates the image and network like the UI does, and editing through the API keeps compose labels it doesn't manage.
- OpenPanel > Backups: restored DNS zone files go through the same `$INCLUDE`/`$GENERATE` checks as normal zone edits.
- OpenPanel > SSL: an uploaded custom private key is staged owner-only and always removed, and certificate issuer/subject are escaped on the SSL details page.
- OpenPanel > WAF: the CRS anomaly-scoring rules can't be disabled per domain anymore, it turned off blocking while the WAF still showed as enabled.
- OpenPanel > WordPress: auto-login requires POST, so it can't be triggered by a cross-site link.
- OpenPanel > Account: the contact email is validated before saving, and email accounts with dot-only names like `..` are rejected.
- OpenPanel > GoAccess: the stats report is served in a sandbox, so content from visitor data can't run with the panel session.
- The `custom` CAPTCHA provider now fails closed unless `custom_captcha_verify_url` is set, before it accepted any token.
- Redirects and generated URLs only reuse a numeric port from the Host header, the mail security token uses a secure random generator, and `.env` values ending in a backslash are escaped.
- Installer: `rndc.key` is no longer world-readable and `/tmp/redis` gets the sticky bit, so accounts can't touch each other's Redis sockets.
