### 💎 New Features
- [Golub](https://github.com/stefanpejcic/Golub) webmail as an alternative to Roundcube, which stays the default. OpenAdmin > Emails > Settings > Webmail client switches between Roundcube and Golub, or from the terminal: `opencli email-webmail client golub`. Only one runs at a time on port 8080, behind the same webmail domain, and OpenPanel users are logged in from Emails > Webmail without a password like with Roundcube. The update adds the Golub service to the mail server compose file, the image is only pulled when switching to it.

### 💡 New
- `opencli email-webmail client [roundcube|golub]` shows the webmail client users get and switches it, the choice is kept as `WEBMAIL_CLIENT` in the mailserver env so mailserver restarts bring back the chosen one.

### 🔒 Security
- Giving a container the Docker socket (the checkbox on Docker > Add/Edit, or a `/run/user/...` volume) is off unless the admin turns on OpenAdmin > Settings > OpenPanel > Allow the Docker socket in containers (`docker_socket=yes` in openpanel.config). With the socket a container controls every container of the account and can mount any of its files. The update adds `docker_socket=no` and lists containers that already mount the socket, they keep it until removed from the account's compose file.
- Users' own containers can't join the `socket-proxy` network anymore, only cron and backup do. Anything on it could call docker-proxy, which allowed creating a container with any bind mount. The update lists containers that are already on it.
- docker-proxy refuses container create, prune, archive (copying files in or out), update, export, attach and rename, and DELETE/PUT requests. Cron and backups only need to list, inspect, start, stop and exec. The rules are a haproxy template in `/etc/openpanel/docker/socket-proxy/` mounted into docker-proxy, the update adds the mount to every account and recreates docker-proxy where it's running.
