### 💡 New
- **Email Migration** (*OpenPanel > Email > Migrate*): users can copy all folders and messages from another IMAP server (cPanel, Plesk, Gmail, Outlook...) into one of their email accounts. The migration runs in the background as an `imapsync` container under the user's account, one at a time per user, and removes itself when it's done; the log is kept so it can be checked later. A **Test connection** button checks both logins first, messages already copied are skipped so a migration can be run again, and Spam, Junk and Trash folders are skipped by default. Private and reserved source addresses are refused, passwords are passed in files that are deleted once imapsync has logged in, and the server runs at most 10 migrations at once (`imapsync_max_jobs` in `openpanel.config`). The update enables the new `email_migrate` module on servers that have the email modules, and adds it to every feature set that has `email_import`. [Docs](/docs/panel/emails/migrate/)
