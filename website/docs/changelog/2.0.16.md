Released on October 21, 2026.

### 🐛 Bug Fixes
- `opencli docker-update` left a container on the old image when another container was created depending on it (e.g. apache on php-fpm), because podman-compose couldn't remove it, started it again and reported success. The container and its dependents are now removed and recreated.
- [emails created via terminal do not appear in OpenPanel UI on /emails UNTIL new email is created via gui #1201](https://github.com/stefanpejcic/OpenPanel/issues/1201)
- [User backups for emails contain only dangling symliks #1197](https://github.com/stefanpejcic/OpenPanel/issues/1197)
- [OpenPanel 2.0.15 update gets stuck at “Updating installed locales” on servers with multiple languages #1199](https://github.com/stefanpejcic/OpenPanel/issues/1199)
- [Bug handling suspended domains: user can delete domain and add it again to remove a suspension #1198](https://github.com/stefanpejcic/OpenPanel/issues/1198)
- `opencli sentinel` OOM alerts now list the killed processes with user, PID, container, memory and time instead of only a count, and kills inside users' rootless containers are no longer left out of the details.
- Fixed several bugs with `opencli docker-backup` script.
- `opencli domains-unsuspend` now removes the domain's saved copy from `suspended_domains/`, before it stayed there and `opencli domains-suspend` refused to suspend the domain again ("Domain is already suspended."). `domains-suspend` now checks the live Caddy file, and the update removes copies left behind for domains that aren't suspended.
- Restoring a database from Backups > Restore now streams the dump into the database container instead of loading it into memory, so large dumps, triggers, procedures and PostgreSQL `COPY` data restore correctly.
- A comment given to `opencli domains-suspend` could add lines to the domain's Caddy file, line breaks and control characters are now removed from it.
- The Suspended Website editor on OpenAdmin > Domains > Domain Templates saved to `/etc/openpanel/nginx/suspended_website.html`, which isn't used, it now edits `/etc/openpanel/caddy/templates/suspended_domain.html` that Caddy serves.
- Suspending and then unsuspending an account reactivated its domains that were suspended on their own, they now stay suspended.
- `opencli domains-unsuspend` on a domain of a suspended account deleted the saved copy of its original vhost, and `opencli domains-suspend` overwrote it, both now refuse until the account is unsuspended.
- The header row of the tables on Access Logs, WAF Logs, Email Import and Passkeys had a dark border instead of the light one used on other pages.
- [OpenPanel update gets stuck at "Updating installed locales" on servers with multiple languages #1199](https://github.com/stefanpejcic/OpenPanel/issues/1199): `opencli update` now stops a stuck locale download after 60 seconds (up to 3 tries) and continues, and a failed download no longer empties the existing locale or `features.json` file.
- Creating a reseller through `/api/settings/resellers` now uses `opencli admin new --reseller` like OpenAdmin does, so the limits from `reseller_template.json` are applied, and it's refused while resellers are disabled.
- A reseller could create users through `POST /api/users` without any of their limits being checked, the users are now created under the reseller and their limits apply.
- Changing a user's plan didn't check whether the plan is allowed for the user's reseller, `opencli user-change_plan` now refuses plans the reseller can't assign.
- Resellers whose allowed plans were set from Edit Plans & Limits or the API saw no plans on Hosting Plans, and every plan on Add User. Edit Plans & Limits also didn't show which plans were already selected.
- A reseller without a limits file in `/etc/openpanel/openadmin/resellers/` had no limits at all, the file is now created from `reseller_template.json` when it's missing.
- `opencli admin update` exited with 0 even when the update failed.
- `opencli files-fix_permissions` no longer changes owners or modes through symlinks inside the user's files, and refuses a path outside `/var/www/html/`.
- `opencli ftp-add` and `opencli ftp-path` refuse a folder that points through a symlink, and set ownership and modes only inside `/var/www/html/`.
- `opencli domains-add` creates the docroot, the default page and the vhost file without following symlinks in the user's volumes.
- `opencli domains-docroot update` now validates the new docroot (before it checked the old one), and creates it and edits the vhost without following symlinks.
- `opencli domains-ssl custom` refuses `..` and symlinked certificate or key paths, and checks that the key is a valid private key.
- `opencli php-domain --update`, `opencli domains-varnish` and `opencli domains-delete` no longer follow symlinks when editing vhost files, adding the WordPress helper plugin or removing .onion folders.
- `opencli files-malware_scan` moves infected files into `.quarantine` without following symlinks on either side.
- `opencli user-backup` writes the archive into the user's `_backups` folder without following symlinks, and stops if the folder itself is a symlink.

### 💡 New
- [Reseller Packages #1177](https://github.com/stefanpejcic/OpenPanel/discussions/1177): new [Hosting Plans > Reseller Packages](/docs/admin/plans/reseller_packages/) page with limit templates (max accounts, max disk, allowed user packages) for reseller accounts. Pick a package when creating a reseller or move a reseller to another one from Edit Plans & Limits, and editing a package updates all resellers on it. Moving to a package below the reseller's current usage is refused.
- `opencli admin new USER PASS --reseller --plan=PACKAGE` and `opencli admin update USER --plan=PACKAGE` create a reseller on a package and move it to another one.
- New `/api/plans/resellers` API endpoint to manage reseller packages, and `/api/settings/resellers` accepts `plan` on create and a new `change_plan` action, so billing systems can sell reseller hosting.
- Max Disk Usage of a reseller is now a soft limit: once reached, the reseller can't create users, users can't be moved to them and their users can't be changed to a plan with more disk.
- `POST /api/users` accepts `reseller` to create the account for a reseller.
- Resellers can now use [more OpenAdmin pages](/docs/admin/accounts/resellers#pages-resellers-can-use), each limited to their own users, domains and emails: Domains, DNS Zone Editor, Rate Limiting, Email Accounts and Queue, Import Account, FTP, Web Firewall domains and logs, ImunifyAV per user, Resource Usage, Scheduled Actions (read only) and Locales, plus the same API endpoints with a reseller token.
- Import Account can upload a backup from your computer, and `opencli user-restore --reseller=NAME` restores an account for a reseller within their limits.
- `opencli waf user USERNAME enable|disable` turns CorazaWAF on or off for all current and new domains of a user, and `opencli waf user USERNAME` shows the user's WAF status.
- Backups > Restore is redesigned: it opens with backup stats and a tile per type (Everything, Website Files, Databases, Emails, Domains, Cron Jobs), and each type lists its own backups so you can restore just what you need. The Databases tab lists each database once with an older-backup picker and restores several at a time, and any restore that brings back cron jobs now restarts the cron container so they take effect.
- [Domains suspended by the Administrator are locked for the user #1166](https://github.com/stefanpejcic/OpenPanel/discussions/1166): OpenPanel shows **Suspended by Admin** with the reason and refuses to unsuspend, delete or change the domain, its VirtualHosts or its DNS zone. Users can still suspend and unsuspend their own domains. See [Suspend a domain](/docs/admin/domains/domains/#suspend-a-domain).
- [Suspension reasons](/docs/admin/domains/file_templates/#suspension-reasons): pick a reason and an optional comment when suspending a domain in OpenAdmin, from the bulk actions or the API. Visitors see the reason's page and the user sees its name. Reasons are managed on OpenAdmin > Domains > Domain Templates, with Copyright / DMCA Violation, Overdue Payment / Billing and Phishing / Security Violation included.
- `opencli domains-suspend` has new `--by=admin|user` and `--template=<reason>` flags, and `opencli domains-unsuspend` has `--by=admin|user`.
- [Error Logs #1179](https://github.com/stefanpejcic/OpenPanel/discussions/1179): new [Statistics > Error Logs](/docs/panel/statistics/error_logs/) page with PHP, web server, database, application and HTTP 5xx errors of all websites in one place, filtered by website (including subfolder sites), service, severity, date and text, with Copy and Download for support. WordPress sites show their latest errors on the Debugging tab. Enable the `error_logs` module in OpenAdmin > Settings > Modules.
- New [Daily Summary](/docs/panel/statistics/daily_summary/) module: every morning each user's previous day is saved, starting with what needs attention and a link to the page that fixes it, then traffic per website, disk, CPU and memory use, logins and account changes. Shown on Statistics > Daily Summary and kept for 90 days, and the Dashboard shows a notice when yesterday's summary found something. Enable the `summary` module in OpenAdmin > Settings > Modules.
- New email notifications on [Account > Notifications](/docs/panel/account/notifications/): **Vulnerable WordPress site**, **Visitors blocked by rate limit**, **Daily summary** and **Daily error report**. Options for features the user doesn't have are hidden.
- `opencli user-daily_summary` saves the daily summaries and emails them to users who turned them on, `opencli user-error_report` sends the daily error report. Both run daily from cron and have a `--dry-run` flag.
- `opencli sentinel` can check every 6 hours whether visitors were blocked by the request rate limits and notify the admin and the domain owners, turned on with **Visitors blocked by rate limit** in OpenAdmin > Settings > Notifications (off by default).
- `opencli sentinel` now blocks IPs with too many connections for 60 minutes using CSF, Cloudflare, whitelisted and server IPs are never blocked.
- `opencli sentinel` alerts when more than 500 emails are in the mail queue with the top senders, and puts the queued emails of the top local sender on hold.

### 💅 Polish
- The update pulls the latest image of every PHP version used on the server and recreates the running php-fpm containers on it, for the [critical PHP vulnerabilities CVE-2026-109618 and CVE-2026-109619](/blog/php-security-update-openpanel). `opencli docker-update IMAGE` now updates a single image, recreates only the running containers that use it, and reloads the user's webserver after a php-fpm container is recreated. [Docs](/docs/articles/opencli/docker#update)
- `opencli sentinel` now frees disk space in steps when disk usage is over the threshold, safest first (journal, package cache, old logs, logs over 1GB, unused podman data and shared images, users' Trash), stops once it's back under the threshold, and the alert says what each step freed.
- `opencli sentinel` high load, CPU and RAM alerts now name the 3 users using the most.
- `opencli sentinel` turns on SYN cookies when it detects a possible SYN flood.
- `opencli waf enable` no longer turns WAF back on for domains of users that have it turned off with `opencli waf user USERNAME disable`.
- For accounts with admin-configured backups, the Backups page now opens Restore & Download directly since there is nothing to configure.
- Downloading a backup from Backups > Restore now streams it straight from the destination instead of saving a temporary copy first.
- The VirtualHost, Varnish and Caddy templates moved from OpenAdmin > Domains > Domain Templates to their own [VirtualHost Templates](/docs/admin/domains/vhost_templates/) tab at `/domains/vhost-templates`, and to the new `/api/domains/vhost-templates` API endpoint. `/api/domains/file-templates` now only handles `default_page`, `suspended_user` and `suspended_website`.
- The Git column on OpenAdmin > Websites is now shown by default.
- `opencli websites-vulnerability --all` now emails each website owner the new vulnerabilities found on their WordPress websites.
- `opencli imunify notify` now also emails the user when an ImunifyAV scan finds malware in their account.
- The date range picker from Account > Activity is now shared, and used on Statistics > Error Logs too.
