Not yet released.

### 💎 New Features
- OpenAdmin > Settings > OpenPanel: every option has a help tooltip that explains what it does.
- The WordPress plugins set, themes set and profiles moved from OpenAdmin > Settings > Custom Code to a new [WordPress section on OpenAdmin > Settings > OpenPanel](/docs/admin/settings/openpanel#wordpress).
- OpenAdmin > Settings > OpenPanel > WordPress: the default plugins and themes sets are shown side by side, and several WordPress profiles can be added in one save with **+ Add another profile**.

### 🐛 Bug Fixes
- OpenAdmin > Accounts > Create: the progress could freeze on "Configuring rootless Podman" while the account was still being created. OpenAdmin cut every response after 30 seconds, and a container image download printed a progress line longer than the page could read.
- OpenAdmin > Settings > Notifications: the toggles for newer alerts couldn't be saved on servers whose notifications.ini didn't list them yet.
- OpenAdmin > Settings > General: switching dev mode back off before restarting OpenAdmin was ignored, and the page kept showing the old value.
- OpenPanel login page: the favicon set on OpenAdmin > Settings > OpenPanel was not used.
- Forbidden usernames and restricted domains: the last entry was ignored when the list didn't end with a new line, and entries saved from the browser could fail to match.
- OpenAdmin > Server > SSH: password authentication, public key authentication, root login and port were ignored on servers where a file in `/etc/ssh/sshd_config.d/` (like cloud-init's) set them, and a setting missing from `sshd_config` was never written. They are now also saved in `sshd_config.d/00-openadmin.conf`, checked with `sshd -t` before SSH restarts, and the page shows what SSH actually uses.
- OpenAdmin > Services > Limits: a new CPU or memory limit only took effect when the service was recreated. It's now applied to the running container right away, the message lists which ones.
- OpenAdmin > Settings > Modules: switching off SSL, Redirects, PHP Options, PHP INI editor, PHP Extensions, phpMyAdmin, Edit VirtualHost, Document root, Domain logs, Capitalize domains, Domain suspend or Temporary links had no effect, users kept them as long as their feature set had them. They are now removed for users like every other module. New installations have them switched on, on existing servers check Settings > Modules after updating.
- OpenPanel > FTP: the plan's FTP account limit was shown on the dashboard but not enforced, users could create any number of FTP accounts. Creating one over the limit is now refused, also through the API.
- OpenAdmin > Settings > Notifications: an alert that wasn't in `notifications.ini` yet showed as off, saving the page then turned it off for real. The Admin/Reseller deleted, Reseller renamed, OpenAdmin port changed, User near or over disk limit and Docker image update failed alerts can now be turned off too.
- OpenAdmin > Settings > Locales: a new default locale reached users only after up to 24 hours.
- OpenAdmin > Settings > Custom Code > Before startup: the script never ran, it was saved in `/root` which the OpenPanel container doesn't mount. It's now kept in `/etc/openpanel/openpanel/custom_code/run_on_startup`, an existing script is moved there.
- OpenAdmin > Settings > General: a new `/openpanel` path or OpenPanel/OpenAdmin port didn't take effect, Caddy wasn't reloaded and the new port wasn't opened on the firewall.
- OpenAdmin > Settings > Modules: enabling Dynamic DNS also set up BIND monitoring as if the DNS module was on.
- OpenAdmin > Settings > OpenPanel > Logout URL had no effect, OpenPanel read a different config key. It now redirects users there after logout.
- OpenAdmin > Emails > Settings: changes such as turning POP3 off never reached the mail server, Roundcube depends on it so podman kept the old container. It's now recreated with Roundcube.
- OpenAdmin > Emails > Accounts: lifting a send or receive restriction kept rejecting mail until the mail server restarted, Postfix is now reloaded after every change.
- OpenPanel > Domains > New: after an error the log with the reason (e.g. domain limit reached) no longer opened on its own.
- [Goaccess: No authentication provided. #1358](https://github.com/stefanpejcic/OpenPanel/issues/1358)
