### 💎 New Features
- OpenAdmin > Settings > OpenPanel: every option has a help tooltip that explains what it does.
- The WordPress plugins set, themes set and profiles moved from OpenAdmin > Settings > Custom Code to a new [WordPress section on OpenAdmin > Settings > OpenPanel](/docs/admin/settings/openpanel#wordpress).
- OpenAdmin > Settings > OpenPanel > WordPress: the default plugins and themes sets are shown side by side, and several WordPress profiles can be added in one save with **+ Add another profile**.

### 🐛 Bug Fixes
- OpenAdmin > Settings > OpenPanel > Logout URL had no effect, OpenPanel read a different config key. It now redirects users there after logout.
- [Goaccess: No authentication provided. #1358](https://github.com/stefanpejcic/OpenPanel/issues/1358)
