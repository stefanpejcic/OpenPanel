Not yet released.

### 💎 New Features
- OpenAdmin > Settings > OpenPanel > Theme: installed themes have an **Uninstall** button that deletes the theme's files. Users who picked that theme for themselves go back to the server theme, and if it was the server theme, OpenPanel goes back to Default. When the theme list on GitHub has a newer version than the installed one, an **Update to x.y.z** button replaces the theme files and keeps the saved colours ([#1385](https://github.com/stefanpejcic/OpenPanel/discussions/1385)).

### 💅 Polish
- OpenAdmin > Server > Swap: the size field has a maximum based on free disk space (1 GB always stays free), checked on the page and on the server, and the page shows how much disk is free.
- OpenAdmin > Server > Swap: Drop Swap and resizing the swap file are refused when what's in swap wouldn't fit in available RAM, and the page shows how much is in swap next to the available RAM.
- OpenAdmin > Server > Swap: a "What's in swap" table lists the processes with the most memory swapped out, with links to the OpenPanel user that owns them.

### 🗑️ Removed
- `opencli dev`, the command that copied a changed file into the OpenPanel container and restarted it. It wasn't used anymore.

### 🐛 Bug Fixes
- The Modern theme moved to github.com/caesarmind, the update points the Theme URI and Author URI of an installed copy there.
- OpenAdmin > Settings > OpenPanel: the "AI Assistant module is disabled" notice only shows once an API key is set.
- OpenAdmin showed "Enterprise license" in the top bar and on the login page for any key that starts with `enterprise`, even after the license stopped being valid. The label, the Enterprise menus and the Enterprise-only domain options now follow the license check and fall back to Community.
- Sentinel Firewall: lfd never blocked any brute force login (SSH, FTP, email) on servers that log only to the systemd journal, which is the default on Ubuntu 26.04 and Debian 12 and newer. lfd reads log files like `/var/log/auth.log`, `/var/log/secure` and `/var/log/messages`, and without `rsyslog` they don't exist, so the deny list stayed empty. The installer now installs and enables `rsyslog` together with the firewall, and the update installs it on existing servers that have the firewall and restarts lfd.
- New installations keep more IPs on the Sentinel Firewall deny list: `DENY_IP_LIMIT` 500 (was 200) and `DENY_TEMP_IP_LIMIT` 250 (was 100), so attackers stay blocked longer before the oldest entries are dropped to make room.
