Released on September 22, 2026

### Polish
- `GET` changed to `POST` on these routes in OpenAdmin: `/service/{action}/{service_name}` and `/server/processes/{pid}/{action}`.
- Added 'Tasks' widget on OpenAdmin where admins can view currently running opencli commands, and `/tasks` page where they can also manage those and view schedules.
- converted mis-wired GET routes to POST and updated every caller: 16 CMS backup restore/run routes, delete_db_user, delete_postgres_user, delete_mongodb_user, wordpress/reload_data, wordpress/scan, sites/scan.
- Admin-configured backups via OpenAdmin will now disable the backup configuration and destination settings for new users.
- Added option to pause notifications on `OpenAdmin > Notifications` page.
- On new installations autoinstallers for nodejs/python/ruby/java applications will by default have access to `db` network and database containers: mysql/mariadb, postgresql, mongodb.
