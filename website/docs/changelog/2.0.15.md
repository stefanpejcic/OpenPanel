### 💡 New
- OpenAdmin > Security > Web Firewall (Coraza) is split into *Overview*, *Rules*, *Domains* and *Logs* tabs. [Docs](/docs/admin/security/waf/)
  - *Overview*: domains per WAF mode, recently blocked requests, the installed OWASP CRS version with *Check for updates* and *Update rules* (only shown when updates are available), app profiles with the number of domains using each and *Re-download*, and the most attacked domains and most triggered rules.
  - *Rules*: rule IDs and tags can be disabled on all domains, saved to `RESPONSE-999-EXCLUSION-RULES-AFTER-CRS.conf` so CRS updates keep them.
  - *Domains*: every domain with its owner, mode, protection level and disabled rules. Change the mode (Protect, Monitor only, Off) and disabled rules and tags of one domain, or the mode and a disabled rule for all domains of a user.
  - *Logs*: blocked, would block and flagged requests for the whole server, a user or a domain, with the most hit domains, rules triggered (with *Disable for domain/user* and *Disable server-wide*), top IP addresses and latest requests, and *Clear logs*.
