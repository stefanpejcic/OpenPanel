### 💡 New
- OpenAdmin > Security > Web Firewall (Coraza) is split into *Overview*, *Rules*, *Domains* and *Logs* tabs. [Docs](/docs/admin/security/waf/)

### 💅 Polish
- OpenAdmin now shows recommendations across its pages, based on the server and the current settings: auto update policy, default webserver/database/Varnish/PHP version and autostart services, service CPU/RAM limits, nameservers, password reset without SMTP, file manager and MySQL import sizes, trash purge, password and session security, missing PHP versions, locales for where users log in from, SSH port and authentication, swap size, high resource usage, broken cron schedules, processes hogging resources, other open terminal sessions, WAF and basic auth, email services and license due date.
- *OpenAdmin > Settings > Notifications* recommends Website traffic limits from Sentinel's recorded connection peaks, which Services to monitor, and IPs for the Login Whitelist from earlier OpenAdmin logins. User actions are grouped with *All on* / *All off* buttons. [Docs](/docs/admin/settings/notifications)
- *OpenAdmin > Settings > Notifications > Resource Usage* recommends threshold values based on the server's CPU cores, RAM, disk and swap, and warns when a value is set too low. [Docs](/docs/admin/settings/notifications#resource-usage)
- Multiple email addresses and webhooks endpoints can now be set on *OpenAdmin > Settings > Notifications*, each webhook has a *Test* button. [Docs](/docs/admin/settings/notifications#webhook)

### 🐛 Bug Fixes
- `opencli server-migrate` now refuses to run when the destination is the same server, even with `--force`, instead of taking down and re-importing the source's own stack and database.
- `opencli server-migrate` now replaces only the exact old server IP in DNS zones and configuration files, so records like `11.2.3.45` are no longer changed when the old IP is `1.2.3.4`.
- [Installing n8n produces an invalid per-user nginx.conf + a single user's Nginx crash loop takes down global Caddy for all users #1193](https://github.com/stefanpejcic/OpenPanel/issues/1193)
- Max total connections and Max connections per IP above 100 were ignored by Sentinel, which always used its defaults of 5000 and 500.
- `chown: invalid user: ‘testinguser:testinguser’` error on `opencli domains-docroot`.
- OpenAdmin reported an email as sent when the SMTP server rejected it after receiving the message.
- `opencli admin notifications update webhook_url` broke URLs that contain `&` or `|`.
- `opencli domains-cloudflare` now also allows the server's own IPs, so wp-cron and other loopback requests to Cloudflare-only domains no longer get a 403.
