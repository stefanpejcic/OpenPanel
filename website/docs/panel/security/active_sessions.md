# Active Sessions

Displays current active sessions for the user account, showing the IP address, when the session was created, and its status.

Click **Terminate** next to a session to immediately end it and log that session out.

![Active Sessions table with the IP address, creation time, online status and a Terminate action for each session](/img/openpanel-screenshots/account/sessions-list.png#gh-light-mode-only)
![Active Sessions table with the IP address, creation time, online status and a Terminate action for each session](/img/openpanel-screenshots/account/sessions-list_dark.png#gh-dark-mode-only)

## Bulk Actions

Tick the checkbox of one or more sessions, or the checkbox in the table header to select every session shown by the current search. A bar appears at the bottom of the page with the number selected, a **Clear** link and these actions:

![Two sessions selected with the bulk actions bar offering Terminate](/img/openpanel-screenshots/account/sessions-bulk.png#gh-light-mode-only)
![Two sessions selected with the bulk actions bar offering Terminate](/img/openpanel-screenshots/account/sessions-bulk_dark.png#gh-dark-mode-only)

| Action | What it does |
|---|---|
| **Terminate** | Ends the selected sessions. Anyone using them is logged out. |

Your current session can't be selected, it's marked **This session** in the table.

Click an action, confirm it, and it runs on the selected sessions one after another. When it's done the page reloads with a notice listing the sessions it worked for, or which ones failed and why.
