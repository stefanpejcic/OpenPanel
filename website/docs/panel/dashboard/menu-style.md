# Menu Style

OpenPanel has two menu styles:

- **Classic**: features are grouped in expandable sections in the sidebar, for example **MySQL** expands into Databases, Users, Database Wizard and more.
- **Modern**: the sidebar has one link per area, and the pages of that area are shown as tabs at the top of each page. For example, **MySQL** opens the databases list, with tabs for Users, Import, phpMyAdmin, Remote Access, Running Queries and the rest.

This documentation describes the **Modern** menu. Menu paths like **MySQL > Users** mean: click **MySQL** in the sidebar, then the **Users** tab.

## Modern menu

In the Modern menu:

- The sidebar is split into sections: the main areas at the top, then **Databases**, **Configure** and **Monitor & Secure**.
- The breadcrumbs at the top of the page follow the same structure, for example **Databases > MySQL > Users**.
- Pages that manage a single service, like MySQL, Redis or the web server, have **Terminal** and **Logs** tabs that open that service's terminal and logs without leaving the page's area.
- Tabs that open in a new browser tab, like **phpMyAdmin** and **Webmail**, are marked with an arrow icon.
- The dashboard sections are listed in the same order as the sidebar.

## Change the menu style

The default menu style is set by the administrator. To use a different style for your account:

1. Click your profile at the bottom of the sidebar.
2. Next to **Menu style**, pick **Classic** or **Modern**.

The page reloads with the selected style. Your choice is saved in your browser, so it applies until you change it again or clear your browser's cookies.
