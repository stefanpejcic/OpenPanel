# Applications

The **Websites** section in the OpenPanel sidebar provides access to the Auto Installer, Site Manager and WP Manager pages, where you can install and manage WordPress, NodeJS or Python Applications.

![screenshots](/img/panel/v2/new_site_popup.png)

Available pages:

- Site Manager
- [WordPress Manager](/docs/panel/applications/wordpress)
- [Auto Installer](/docs/panel/applications/autoinstaller)
- [Website Builder](/docs/panel/applications/builder/)
