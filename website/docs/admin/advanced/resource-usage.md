# Resource Usage

Real-time server-wide resource usage, for the whole physical/virtual machine OpenPanel runs on (not a single user's account).

Use **OpenAdmin > Server > Resource Usage** to view it.

## Tabs

- **Load** – Current system load averages.
- **CPU** – Per-core CPU usage.
- **RAM** – Memory usage: used, total, and available.
- **Disk** – Disk space usage per mounted volume.
- **Network** – Network I/O.

## History

Click **View Usage History** to open the historical resource usage page, which charts CPU and memory usage over a selectable time range and lists every recorded snapshot in a table below the charts.
