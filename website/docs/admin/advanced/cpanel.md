# Import cPanel Account

Use **OpenAdmin > Advanced > Import from backup** to create an OpenPanel account from a cPanel, CyberPanel, or OpenPanel backup. On the import page, select the backup file and choose the backup type (**OpenPanel**, **cPanel**, or **CyberPanel**) before starting the import.

:::info
This menu item is only available with an **Enterprise** license and is hidden for reseller logins. A **View Logs** button on the same page links to the account import history.
:::

For detailed instructions, see the [Import cPanel backup guide](https://openpanel.com/docs/articles/transfers/import-cpanel-backup-to-openpanel/)
