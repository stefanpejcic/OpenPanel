# License

Add your OpenPanel Enterprise license key to unlock premium features.

## License key

Enter your [OpenPanel Enterprise edition](https://my.openpanel.com/clientarea.php?action=products) license key here. Activating the license enables advanced capabilities such as:

* Email and FTP account management
* Reseller management
* API access
* Billing integrations with WHMCS, FOSSBilling, and more

![License key section with the key field, the Save key, Re-verify and Downgrade buttons and the license details](/img/openadmin-screenshots/license-key.png#gh-light-mode-only)
![License key section with the key field, the Save key, Re-verify and Downgrade buttons and the license details](/img/openadmin-screenshots/license-key_dark.png#gh-dark-mode-only)

**Downgrade** removes the license key and turns off all Enterprise features, after you confirm it. You can add the key again later.

For a step-by-step activation process, see the [Upgrading to OpenPanel Enterprise and activating License guide](/docs/articles/license/upgrade_to_openpanel_enterprise_and-activate_license/).

When the license's next due date is 3 days away or less, a warning is shown under the license details: the license gets suspended on that date, so either renew it or remove the license key to downgrade to the Community edition.

## Contact support

When reaching out to support, generate a system report to provide detailed information about your setup. **Generate report** saves the report on the server and shows the path to the file, send its content to the support team.
