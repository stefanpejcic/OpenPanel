# Summary Reports

The *Emails > Summary Reports* page (`/emails/reports`) shows daily summaries of the mail server log (Postfix), generated every 24 hours.

The page shows a calendar for each month of the selected year. The badge next to each month is the number of daily reports available for it, and the header shows when the reports were last updated and for which server. Click a day that has a report to open that day's summary.
