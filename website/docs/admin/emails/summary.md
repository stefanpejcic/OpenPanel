# Summary Reports

The *Emails > Summary Reports* page (`/emails/reports`) is intended to show daily and monthly reports for all outgoing emails on the server. Currently the page always displays **"No reports yet. Reports are generated every 24h."**, regardless of whether report data exists on the server yet, so treat report browsing on this page as a work in progress.

:::info
Emails are only available on [OpenPanel Enterprise edition](/enterprise)
:::
