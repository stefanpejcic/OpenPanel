# Custom OpenPanel Templates

:::warning
Custom templates are no longer supported. OpenPanel and OpenAdmin templates are now built into the application, so the `template` and `admin_template` settings have no effect and were removed from `openpanel.config`.
:::

To change the look of the OpenPanel interface, use these settings instead:

- [`logo`](/docs/articles/opencli/config/#logo) - logo displayed on every page, the login page and in email footers.
- [`favicon`](/docs/articles/opencli/config/#favicon) - favicon displayed on all OpenPanel pages.
- [`brand_name`](/docs/articles/opencli/config/#brand_name) - name displayed instead of *OpenPanel*.
- [`menu_style`](/docs/articles/opencli/config/#menu_style) - style of the sidebar menu.
- [`filemanager_buttons_style`](/docs/articles/opencli/config/#filemanager_buttons_style) - how action buttons are shown in the File Manager.
